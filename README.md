# Misutgaru

Misutgaru is a Misskey fork focused on a gradual Vue-to-Vune UI migration, a shared motion and Material layer, and lower-overhead backend runtime behavior while preserving the Misskey federation and data-model foundation.

The source is currently an active migration checkpoint rather than a drop-in vanilla tree. New contributors should start with:

- [Current project state](docs/CURRENT_STATE.md)
- [Architecture](docs/ARCHITECTURE.md)
- [Delta from vanilla Misskey](docs/VANILLA_DELTA.md)
- [Source map](docs/SOURCE_MAP.md)
- [Vune migration](docs/VUNE.md)

Important: extracted source archives may not contain the contents of the Vune and o0o0o Git submodules. See the current-state document before attempting a full frontend build.

Misutgaru remains licensed under the repository licenses and retains upstream Misskey attribution.
